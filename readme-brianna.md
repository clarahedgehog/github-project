# The Git Guide — Student Project

> A simple multi-page website made by students to explain the basics of **Git & GitHub**.  
> This repository is part of our version-control course assignment.

## About the Project
This site introduces why version control matters and how to collaborate safely with Git & GitHub:
- Create a repository, link local ↔ remote, and push the first commit.
- Use **branches** for focused work; open **Pull Requests**; resolve conflicts early.
- Practice a **student-friendly daily workflow** (pull → add/commit → push).
